# Портовик

Нативное приложение для macOS, которое показывает, **кто на каком порту** и **кто с кем соединён**:
процессы на Mac, контейнеры Docker и связи между ними — списком, таблицей или схемой.
Без терминала: найти, кто занял порт, и освободить его — в два щелчка.

## Что умеет

- **Три вида.** «Список» — группы (проекты, compose, приложения) с портами и связями в строке.
  «Порты» — таблица, сортировка по любому столбцу. «Схема» — граф: клиенты слева, серверы справа,
  стрелка ведёт в «гнездо» с номером порта.
- **Кто это и откуда.** Понятное имя (Vite, Next.js, Django, PostgreSQL, `main.ts · tsx`…), цепочка запуска
  («iTerm › zsh › npm › node»), рабочая папка и проект, полная команда, пользователь, время запуска,
  процессор и память, служба launchd (`homebrew.mxcl.postgresql@14`).
- **Группы.** Docker Compose — по проекту; процессы на Mac — по папке проекта (корень git) или по приложению;
  папка с одним compose-проектом сливается с процессами этого же проекта на Mac.
- **Связи.** Mac → Mac, Mac → контейнер (через опубликованный порт), контейнер → контейнер,
  контейнер → Mac (`host.docker.internal`). Бегущий пунктир — сейчас идёт обмен (со скоростью),
  бледная линия — связь была недавно.
- **Управление.** Завершить процесс (SIGTERM, при необходимости kill -9 или с правами администратора),
  остановить службу launchd, остановить/перезапустить/запустить контейнер или весь compose-проект,
  логи контейнера, открыть порт в браузере, папку в Finder или Терминале.
- **Подсказки.** Порт виден из сети или только с этого Mac; два процесса на одном порту — предупреждение;
  известные ловушки (AirPlay на 5000/7000 и как его выключить).
- **Поиск.** Введите номер порта — увидите владельца или «Порт 3000 свободен».
- **Строка меню.** Быстрый список «порт — кто» с кнопками «открыть» и «освободить».

## Как это устроено

| Откуда | Что даёт |
|---|---|
| `sysctl KERN_PROC_ALL` | все процессы: PID, родитель, пользователь, время запуска |
| libproc (`proc_pidinfo`, `proc_pidfdinfo`) | сокеты своих процессов с точными адресами, путь, аргументы, папка, CPU/память |
| `netstat -anv` | сокеты процессов других пользователей (root) и счётчики байт для скорости обмена |
| `launchctl list` | какие процессы — службы launchd |
| Docker Engine API через unix-сокет | контейнеры, порты, compose-метки, сети; остановка/запуск; логи |
| `docker exec … cat /proc/net/tcp` | соединения изнутри контейнеров (раз в 8 с, только пока окно на экране) |

Пары сокетов «клиент → слушающий порт» на loopback и адресах Mac превращаются в связи. Порт, опубликованный
контейнером, приписывается контейнеру, а не Docker Desktop, — поэтому «Завершить» там означает «остановить
контейнер», а не убить Docker.

Что не видно: UDP-связи (у UDP нет соединений — видны только занятые порты), короткие запросы между двумя
обновлениями (их подхватывает «память связей»), команда и папка процессов root без прав администратора,
соединения внутри контейнеров без утилиты `cat` (distroless).

Поддерживаются Docker Desktop, OrbStack, Colima, Rancher Desktop и Podman (docker-совместимый сокет).

## Сборка

```bash
git clone https://github.com/garik-sukhanov/portovik.git
cd portovik
./build.sh            # → build/Портовик.app, затем перетащите в «Программы»
swift test            # разборщики, раскладка схемы, живой тест «сервер + клиент + kill»
PORTOVIK_DOCKER_IMAGE=caddy:2-alpine swift test --filter testDocker   # временный контейнер
```

Нужны macOS 14+ и Xcode (Swift 6). Внешних зависимостей нет.

## Устройство кода

- `Core/ProcessInspector.swift` — sysctl и libproc.
- `Core/SystemTools.swift` — запуск утилит, разбор `netstat` и `launchctl`.
- `Core/DockerClient.swift` — HTTP поверх unix-сокета, разбор `/proc/net/tcp`.
- `Core/Classifier.swift` — что это за процесс, к какому проекту и приложению относится.
- `Core/Scanner.swift` — сборка снимка: карточки, группы, связи, конфликты портов.
- `Core/Monitor.swift` — автообновление и действия (завершить, остановить, логи).
- `UI/` — список, таблица, схема (`GraphLayout` — слои и барицентры, пунктир — Core Animation), панель подробностей, строка меню.
